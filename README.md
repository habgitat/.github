# Habitual · house notes

This repository holds the [public organization profile](profile/README.md) for [habgitat](https://github.com/habgitat) and the naming and release conventions used across Habitual.

## Names and scope

| Name | Role |
| --- | --- |
| **Habitual** | The umbrella identity for personal projects, tools, and experiments from the Habitat. |
| **habgitat** | Habitual's GitHub home. |
| **Habitual Press** | The publishing project and imprint: preparing editions and developing tools for publishing and bookmaking. |
| **Habitual Bindery** | The internal name for the physical workshop, its buildout, equipment, materials, methods, and individual build records. |

Press's scope includes digital editions, print-ready files, software, templates, and physical books. Its tools and releases may eventually outnumber its bound editions. A release can stand on its own without becoming a bound book.

The Bindery does not need a separate public identity or an explicit credit in books. Its name is useful within the workshop and its records.

## Shared house mark

The hourglass is the shared mark of Habitual and its projects. It can appear on bound books, in digital editions, and alongside tools and other releases. On a physical book, it can represent the Bindery's work without spelling out the workshop's name.

## House vocabulary

| Operation | Description of its work |
| --- | --- |
| **Habitual Press** | *Habitually pressed* |
| **Habitual Bindery** | *Habitually bound* |

These phrases describe the work. They can be used together as *habitually pressed and bound* where appropriate.

## Pressed and Bound dates

| Label | Meaning | Applies to |
| --- | --- | --- |
| **Pressed** | The date that an edition or tool version was released by Habitual Press. | The specific edition or version. |
| **Bound** | The date that an individual physical copy was completed in the Bindery. | That copy. |

One edition can have a single Pressed date and multiple copies with different Bound dates. Digital editions and tools carry only Pressed. A copy made later retains its edition's Pressed date and records its own Bound date.

## Repository layout

- **`.github`** holds the organization profile and shared house notes. Shared GitHub templates and contribution guidelines can be added when needed.
- **`tools`** can be created when there are shared scripts to put in it.
- Individual projects earn their own repositories as they develop.

Edit `profile/README.md` to update the public organization introduction. Keep the detailed conventions here and each project's documentation in its own repository.
